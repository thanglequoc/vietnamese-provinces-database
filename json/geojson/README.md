# GeoJSON GIS Export

> Created at:  Fri, 14 Aug 2026 00:30:01 +0700

This folder contains GeoJSON exports generated by the GIS dataset writer.

## Folder Structure

Each province is exported to:

```
{province_code}_{province_code_name}/
  {province_code}_{province_code_name}.geojson
  wards/
    {ward_code}_{ward_code_name}.geojson
```

## GeoJSON Shape

Each file is a valid GeoJSON `FeatureCollection` with:

- top-level `bbox`
- exactly one `Feature`
- feature `id` set to the unit code
- feature `bbox`
- geometry and properties as generated by the GIS writer

## Viewing The Result

Open https://geojson.io and load any `.geojson` file from this folder to inspect the geometry and properties.
